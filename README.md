# ToDo Application

Full-stack ToDo app with React, Node.js, Express, and MongoDB.

## Setup

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Prerequisites
- Node.js installed
- MongoDB running on localhost:27017

## Features
- Create new todos
- Read all todos
- Update todo text and completion status
- Delete todos
- Data persists in MongoDB
